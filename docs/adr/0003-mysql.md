# 0003. MySQL 8.4 LTS 사용

- 상태: 확정 (2026-10-27)

## 맥락
관계형 DB를 정해야 한다. 후보는 MySQL, PostgreSQL.

## 결정
MySQL 8.4 LTS를 쓴다.

## 이유
- 참고한 서비스 기업 백엔드 공고 대부분이 MySQL을 쓴다
- 이 프로젝트의 학습 목표인 인덱스, 실행계획, InnoDB 락 관련 자료가 많다
- 8.0은 2026년 4월 지원이 끝나 LTS인 8.4를 쓴다

## 대안
- PostgreSQL: 위치 검색(PostGIS), 벡터 검색(pgvector), 범위 겹침 제약 등이 강하지만, 이 프로젝트의 핵심 문제(정원 초과 방지)에는 MySQL로 충분하다

## 결과
- 위치 기반 검색이 필요해지면 MySQL 공간 함수 또는 Elasticsearch로 해결한다
