# 0001. Java 21 사용

- 상태: 확정 (2026-10-27)

## 맥락
새 프로젝트의 Java 버전을 정해야 한다. 후보는 17, 21, 25 (모두 LTS).

## 결정
Java 21을 쓴다.

## 이유
- Azul 「2025 State of Java」 조사 기준 사용률이 17(34%)에 이어 21(31%)로, 1년 사이 8%에서 빠르게 늘었다. 신규 프로젝트에서 많이 쓰는 버전이다
- 가상 스레드를 알림 발송 같은 I/O 구간에 적용해 볼 수 있다
- 25는 가장 최신 LTS지만 참고 자료가 아직 적다

## 대안
- 17: 가장 많이 쓰고 자료가 많지만, 가상 스레드가 없다
- 25: 최신이지만 자료가 적다

## 결과
- 8 시절 문법(람다, 스트림, Optional)은 그대로 쓰므로 8, 11을 쓰는 조직에서도 문제없다
