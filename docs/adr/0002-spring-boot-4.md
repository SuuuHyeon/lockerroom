# 0002. Spring Boot 4.1 사용

- 상태: 확정 (2026-10-27)

## 맥락
Spring Boot 버전을 정해야 한다. 국내 강의와 자료는 3.x 기준이 많다.

## 결정
Spring Boot 4.1을 쓴다.

## 이유
- 3.x는 2026년 6월 3.5.16을 끝으로 무료(OSS) 지원이 끝났다. 이후 보안 패치가 무료로 나오지 않는다
- 컨트롤러, JPA, Security 등 핵심 사용법은 3.x 자료가 대부분 그대로 통한다

## 대안
- 3.5: 자료가 많지만 지원이 끝난 버전으로 새 프로젝트를 시작하게 된다

## 결과
- 3.x 자료와 다른 부분(Spring Framework 7, 일부 라이브러리 버전 변경 등)은 공식 마이그레이션 가이드로 해결한다
- 4.1과 호환되는 라이브러리 버전(springdoc 등)은 도입할 때 확인한다
