# 라커룸

풋살 소셜 매치 플랫폼. 열린 매치에 혼자서도 한 자리씩 참가할 수 있습니다.

학습과 포트폴리오를 위한 프로젝트로, 실제 서비스(플랩풋볼)의 구조를 분석하고 핵심 문제(정원이 있는 매치의 동시 신청, 대기와 빈자리 알림, 자동 확정과 취소)를 직접 구현하고 측정합니다.
